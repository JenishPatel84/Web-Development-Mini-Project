# JavaScript ES6 Concepts

This repository contains beginner-friendly JavaScript programs covering important ES6 features and core JavaScript concepts, with practical examples and backend-related use cases.

## Topics Covered

| File | Concepts |
|---|---|
| `class.js` | Classes, Constructors, Getters, Setters, Static Methods |
| `inheritance.js` | Class Inheritance, `extends`, `super` |
| `prototypes.js` | Prototypes, Prototype Chain, Object Inheritance |
| `closure.js` | Scope, Closures, Data Privacy, Function Factory |
| `hoisting.js` | Variable Hoisting, Function Hoisting, TDZ |
| `promise.js` | Promises, Promise Chaining, Promise.all, Promise.allSettled |
| `async.js` | Async/Await, Multiple Await, Error Handling |
| `errorHandeling.js` | Try-Catch, Finally, Throw, Custom Errors |
| `JSONParsing.js` | JSON.stringify(), JSON.parse(), JSON Error Handling |

## How to Run

1. Install [Node.js](https://nodejs.org/).
2. Clone the repository.
3. Open the `ES6Javascript` folder.
4. Run any JavaScript file:

```bash
node filename.js
```

## Technologies Used

- JavaScript (ES6+)
- Node.js
