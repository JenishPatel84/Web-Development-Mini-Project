A collection of **frontend web development mini-projects** built using **HTML, CSS, and JavaScript**.

This repository contains several practical projects created to strengthen my understanding of **DOM manipulation, JavaScript events, form validation, API integration, dynamic UI updates, and interactive web development**.

# 2. 🐙 GitHub API Card Generator

A web application that allows users to enter a GitHub username and dynamically generate a GitHub profile card.

The application communicates with the GitHub API using:

```text
https://api.github.com/users/{username}
```

### Information Displayed

* Profile avatar
* Name
* Username
* Bio
* Location
* Followers
* Following
* Public repositories

The project also handles invalid usernames and displays an error message when a GitHub profile cannot be found.

### Concepts Practiced

```text
API Integration
HTTP Requests
XMLHttpRequest
JSON Parsing
DOM Manipulation
Event Handling
Dynamic HTML
Error Handling
```

# 💻 How to Run the Projects

Since these are primarily frontend projects, they can be run directly in a web browser.

### 1. Clone the Repository

```bash
git clone https://github.com/JenishPatel84/Web-Development-Mini-Project.git
```

### 2. Navigate to the Project

```bash
cd Web-Development-Mini-Project
```

### 3. Open a Project

For example:

```text
Form_Validation/index.html
```

or

```text
Weather_App/index.html
```

### 4. Run With Live Server

For the best development experience, open the project using the **Live Server** extension in Visual Studio Code.
